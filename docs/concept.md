# Концепция проекта

**Тема:** Подбор автомобилей на основе машинного обучения и оценки рыночной цены.

## Название проекта

**Car Advisor MD** — ML-помощник покупателя подержанного автомобиля на рынке Молдовы. Система будет оценивать
справедливую цену и объяснять её, подбирать выгодные предложения, а AI-агент — рекомендовать действие
с согласованием через n8n.

## Бизнес-задача

На вторичном рынке Молдовы (основная площадка — 999.md) цены на одинаковые автомобили различаются в разы.
Покупатель не может понять, справедлива ли цена. Он переплачивает или попадается на «слишком дешёвые»
объявления со скрытыми дефектами и мошенничеством. Продавцу, автосалону (trade-in), автоподборщику, лизинговой
или страховой компании нужна быстрая и объективная оценка стоимости автомобиля и прозрачный процесс
согласования сделки.

Что должна решать система:

1. **Оценка рыночной цены** автомобиля по его характеристикам и типичный диапазон цен.
2. **Вердикт по цене продавца**: подозрительно дёшево / ниже рынка / рыночная / выше рынка / сильно завышена.
3. **Объяснение оценки**: какие характеристики повышают или снижают цену и на сколько евро. Это аргументы для торга.
4. **Подбор** выгодных предложений под бюджет и требования (кузов, топливо, КПП, год, пробег, марки).
5. **AI-агент** анализирует результат модели и риски и рекомендует действие: *покупать, торговаться до
   целевой цены, проверить перед сделкой, отказаться*.
6. **Согласование** важных решений менеджером (human-in-the-loop).

Метрики успеха: MAE и MAPE оценки, доля оценок с ошибкой ≤ 20%, калибровка интервалов цены.

## Открытые данные

| Источник | Что даёт | Доступ |
|---|---|---|
| **Kaggle: [Cars for sale in Moldova](https://www.kaggle.com/datasets/alexandrududa/cars-moldova)** (`alexandrududa/cars-moldova`), лицензия **CC0** | 41 007 объявлений 999.md (2021): марка, модель, год, кузов, пробег, объём двигателя, топливо, КПП, цена в € | публичный Kaggle API без ключа: `https://www.kaggle.com/api/v1/datasets/download/alexandrududa/cars-moldova` |
| **NHTSA** — Recalls, Complaints (правительство США) | отзывные кампании и жалобы владельцев по марке/модели/году | `https://api.nhtsa.gov/recalls/recallsByVehicle` — без ключа |
| **Национальный банк Молдовы** — официальные курсы | курс EUR → MDL на дату | `https://www.bnm.md/en/official_exchange_rates?get_xml=1&date=DD.MM.YYYY` — без ключа |

**Сделано на этапе 1.** Датасет загружается в БД (SQLite, PostgreSQL через `DATABASE_URL`) и проходит
проверку качества: 11 правил. Удаляются дубликаты (9%), заглушки года и пробега, невозможные значения, групповые
выбросы цены. Исправляется объём двигателя, указанный «в литрах × 100». Итог: из 41 007 объявлений остаётся
32 945 (80,3%), из них 1 647 отложены как «новые» для будущей проверки модели на невиданных данных.

## ML-часть (план)

* **Задача:** регрессия, целевая переменная — **цена в евро** (`price_eur`), обучение на `log(цены)`
  (по EDA распределение цены сильно скошено вправо).
* **Признаки** (уже реализованы): марка, модель (марка + модель, ≈900 значений), тип кузова, топливо, КПП,
  **возраст** (год объявления − год выпуска), пробег, объём двигателя, **пробег в год**.
* **Модели для сравнения:** Ridge (линейный бейзлайн), Random Forest, LightGBM, CatBoost.
* **Протокол:** hold-out 20%, 5-fold кросс-валидация на обучающей части, выбор модели по MAE, затем подбор
  гиперпараметров. Проверка на отложенных «новых» объявлениях.

## Explainable AI (план)

* для пользователя — SHAP-объяснение каждой оценки: вклад каждого признака в евро;
* для аналитика — глобальная важность признаков (SHAP, permutation importance), кривая амортизации,
  анализ ошибок по сегментам.

## Роль AI-агента (план)

Агент сам планирует шаги и вызывает инструменты: поиск объявлений в БД, оценка цены ML-моделью, статистика
рынка, отзывные кампании (NHTSA), курс валют (НБМ), формирование отчёта, заявка на согласование.
По результату модели и рискам он рекомендует действие: **BUY / NEGOTIATE / VERIFY / AVOID**.

## RPA и автоматизация (план)

n8n-workflow: агент отправляет рекомендацию → письмо менеджеру с кнопками «Одобрить / Отклонить» → после
решения человека запись в Google Sheets и уведомление клиенту. Агент только *рекомендует*, действие
выполняется после решения менеджера.

## Бонус (план)

MLflow для экспериментов, Docker Compose, мониторинг дрейфа данных.
