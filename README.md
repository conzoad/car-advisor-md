# Car Advisor MD — подбор автомобилей и оценка рыночной цены на основе машинного обучения

Учебный проект по машинному обучению (USM). Цель — сквозная система на открытых данных рынка подержанных
автомобилей Молдовы (999.md): данные и БД → проверка качества и EDA → ML-модели оценки цены → объяснимость
(SHAP) → веб-приложение → AI-агент → автоматизация в n8n с согласованием человеком.

**Концепция проекта: [docs/concept.md](docs/concept.md)**

## Что сделано

**Данные.** Открытый датасет [Cars for sale in Moldova](https://www.kaggle.com/datasets/alexandrududa/cars-moldova)
(Kaggle, CC0): 41 007 объявлений 999.md за 2021 год. Скачивается через публичный Kaggle API, происхождение
файла (лицензия, sha256, дата) записывается в [data/raw/SOURCE.json](data/raw/SOURCE.json).

**База данных.** SQLAlchemy, SQLite по умолчанию (PostgreSQL — через `DATABASE_URL`). Таблицы:
`listings_raw` (сырые объявления), `listings` (очищенные), `quality_issues` (журнал: какая строка удалена
или исправлена и по какому правилу).

**Качество данных.** 11 правил, сформулированных по результатам EDA. Отчёт: [reports/data_quality.md](reports/data_quality.md).

| Найденная проблема | Действие | Строк |
|---|---|---:|
| Точные дубликаты объявлений | удаление | 3 743 |
| Пробег-заглушка (< 1000 км у авто старше 3 лет) | удаление | 3 230 |
| Объём двигателя «в литрах × 100» (200 → 2000 см³) | исправление | 915 |
| Пробег больше 1 000 000 км | удаление | 582 |
| Цена отличается от медианы марки/модели/года более чем в 3 раза (цены в леях) | удаление | 312 |
| Год выпуска вне 1980–2021 | удаление | 141 |
| Объём двигателя у электромобиля | исправление | 120 |
| Прочие (цена, объём двигателя вне диапазона) | удаление | 54 |

Итог: из 41 007 объявлений остаётся **32 945 (80,3%)**. Из них 31 298 — для обучения, 1 647 отложены как
«новые» объявления для проверки модели на данных, которых она не видела.

**EDA** — [notebooks/01_eda_data_quality.ipynb](notebooks/01_eda_data_quality.ipynb). Основные выводы:

1. Цена сильно скошена вправо → модель будем обучать на `log(цены)`.
2. Главный фактор — **возраст**: цена быстро падает в первые 10 лет и выходит на плато после ~20 лет.
   Автомобили с автоматом в среднем заметно дороже.
3. Марка и модель задают уровень цены; моделей ≈ 900, нужна обработка категорий с высокой кардинальностью.
4. Пробег коррелирует с возрастом, поэтому добавлен признак **пробег в год**.
5. В данных нет состояния, комплектации и истории ДТП — это ограничит достижимую точность.

**Препроцессинг** — [car_advisor/ml/features.py](car_advisor/ml/features.py): возраст = год объявления − год
выпуска, «марка + модель», пробег в год.

## Запуск

Нужен Python 3.11+.

```bash
make setup        # .venv + зависимости
make data         # загрузка датасета → БД → проверка качества
make notebooks    # пересчитать EDA-ноутбук
make test         # автотесты правил качества и признаков
```

Без `make`: `python -m car_advisor.data.database`, затем `python -m car_advisor.data.quality`.
